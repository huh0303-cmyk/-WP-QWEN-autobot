# SOS 100 표현 카드 (Threads/Instagram)
- 언어: ko(expressions.json), en/ja/zh(expressions_*.json, captions_*.json). 항목 = [표현, 읽는 법, 뜻].
- card.js = 한국어 카드(Threads), card_multi.js = 영/일/중 4:5 카드(Instagram).
- PROCEDURE.md = 한국어 카드 발행 절차. 영/일/중도 같은 방식(Instagram 우선, 같은 핸들 Threads 병행, 계정당 하루 2회).
- 계정: korean_sos1, english_sos1, japanese_sos1, chinese.sos1. 번호는 프로필의 최신 N/100에서 이어서 센다(100 초과 금지).
- 토큰·비밀번호는 저장하지 않는다.
