# K-Health365 최근 발행글 100개 — 조회수 우선 쿠팡 파트너스 매칭 준비

- 작성: 2026-10-31
- 대상: 최근 발행된 공개 게시글 100개 (2026-09-05 ~ 2026-10-31)
- 조회수 원천: Google Analytics 4 `screenPageViews`, 기간 2026-09-05 ~ 2026-10-30 (GA4 시간대 Asia/Tokyo)
- 정렬: 확인된 페이지뷰 내림차순, 동률은 최근 발행일 우선. GA4 행이 없는 글은 조회수 미수집으로 하단 배치.
- 결과: 최근 100개 중 GA4 페이지별 데이터와 제목/경로가 매칭된 글 7개, 조회수 미수집 93개.

## 중요한 데이터 품질 경고

- 워드프레스의 `entry_views` 메타키는 전체 게시글 중 34개에만 존재하며, 최근 100개 글에는 현재 조회수 값이 일관되게 기록되지 않는다.
- 사이트의 `site-stats/v1/visitors`는 페이지별 조회수가 아니라 쿠키 기반 사이트 전체 일일 방문자 근사치다. 게시글별 조회수로 사용하지 않는다.
- 따라서 GA4에서 매칭되지 않은 글은 0회로 단정하지 않고 `미수집`으로 표기했다. 현재 수집된 데이터만으로는 100개 전체의 신뢰할 수 있는 조회수 순위를 만들 수 없다.
- Site Kit/GA4 Analytics는 연결되어 있으나 최근 55일 데이터에서 최근 100개 글과 매칭된 행이 7개뿐이다. 이 원인을 먼저 점검해야 한다.

## 삽입/상품 이미지 적용 원칙

1. 조회수가 확인된 글을 먼저 검토하되, 조회수 미수집 글을 0회로 취급하지 않는다.
2. 제목·본문과 직접 관련된 건강기능식품만 매칭한다. 의료정책·백신·진단·행사·치료제 개발 글에는 억지로 보충제를 붙이지 않는다.
3. 상품별 쿠팡 파트너스 계정에서 생성한 링크만 사용한다. 일반 쿠팡 상품 URL이나 임의 단축 URL을 파트너 링크로 가장하지 않는다.
4. 이미지도 링크와 동일한 상품인지 확인하고, 쿠팡 파트너스에서 제공/사용이 허용된 이미지 또는 사용 권한이 확인된 이미지만 쓴다.
5. 제휴 고지문은 글 첫 부분에 눈에 띄게 표기하고 링크에 `rel="sponsored nofollow noopener"`를 적용한다. 쿠팡 공식 가이드 및 공정위 표시 기준 확인 필요.
6. 기존 상품 카드 중복 삽입 금지. 발행 상태·발행일·기존 본문은 보존한다.

## 실제 실행 차단 조건

- 현재 매칭표에서 계정 소유권이 검증된 파트너 URL은 아직 확인되지 않았다. 과거 사용된 오메가3 단축 URL도 계정 귀속 확인 전에는 소유 링크로 확정하지 않는다.
- 상품별 파트너 링크와 상품 이미지가 확보되기 전에는 게시글 본문에 링크/이미지를 삽입하지 않는다.
- 현재 100회 WPVibe 사용량은 리셋되어 새로 확보됐으나, 조회수 데이터의 공백과 파트너 링크/이미지 미확보는 호출 한도와 별개의 차단 사유다.
