## 업로드 검증과 장애
- 매 편 영수증: `video_id`, 실제 `channel_id`, `privacyStatus=private`, 유형(short/long), 길이, 원본 URL/timecodes/rights, 사진 출처, 스크립트/자막 검수, 제목·영상 중복키, 업로드 시간.
- 내레이션 전체를 순서대로 문장 단위 자막으로 표시한다. 자막은 사진을 가리는 검은 배경 상자 없이 화면 하단 안전영역에 큰 흰색 글자와 굵은 외곽선으로 표시한다. 내레이션 장면의 실제 사진에는 FFmpeg의 느린 확대·이동 효과를 적용하되 인물을 왜곡하지 않는다.
- 쇼츠 마지막 3~4초는 검은 배경 상자 없이 `어떻게 생각하시나요? / A 찬성 / B 반대 / C 더 지켜보기`와 `댓글로 A·B·C를 눌러 참여하세요`를 실제 영상 길이 안에 고정 화면으로 표시한다. 완성 MP4의 끝 1.5초 지점에서 프레임을 추출해 투표 원본과 비교하며, 일치하지 않으면 업로드를 막는다.
- 제작 표지 `cover.jpg`를 YouTube `thumbnails.set`으로 등록한다. YouTube 처리가 끝나 실제 길이가 확인될 때까지 기다린 뒤 썸네일 등록을 재시도하고, 성공하지 않으면 준비 완료로 간주하지 않는다. 이후 실제 채널 ID·비공개 상태·길이·썸네일 상태를 다시 읽어 영수증에 저장한다.
- 정치 쇼츠는 기사에 이름이 확인되는 주요 정치인의 실제 재사용 가능 사진을 중심으로 구성한다. Wikimedia Commons 등 명시적 라이선스와 원본 설명 URL을 `photo-sources.json` 및 설명란에 기록하고, 사건 현장 사진이 아닌 자료사진임을 표시한다.
- 채널 OAuth 권한 없으면 다른 채널 토큰으로 대체 금지. 불명확한 업로드는 원격 조회 후 재시도.
