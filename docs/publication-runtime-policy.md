# 글 발행과 동영상 생성의 중지 범위 — 2026-09-11 사용자 정정

사용자 지시: 동영상 생성은 금지하지만 글 발행은 계속한다. 영상 비용 중지를 글 작성·발행 전체 중지로 확대 해석하지 않는다.

- WordPress, Blogspot, Tistory, 뉴스 글 작성·검수·발행 경로는 활성 상태로 유지한다. 기존 품질 검사와 게시 성공 확인은 유지한다.
- 기존 글쓰기 모델과 인증을 사용한다. 모델·예산을 임의 확장하지 않는다.
- YouTube 영상·플레이리스트·음성·유료 영상 생성 작업은 기존 중지를 유지한다.
- 뉴스룸은 재개 후 새 RSS 기사에 반응한다. 중지 기간 대기 1,195건은 삭제하지 않고 baseline 상태로 보존해 일괄 발행하지 않는다. 일일 발행 횟수 목표를 만들지 않는다.
- 실행 요청, 작성 중, 검토 준비, 실제 게시 완료는 구분한다. 공개 게시 결과와 URL 없이는 게시 완료라고 보고하지 않는다.
