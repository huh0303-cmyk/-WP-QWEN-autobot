## 공통 품질 계약
- 기본 기사 길이 **2,500–4,000자**. 아래 범위는 블로그별 목표(문자 기준, 공백 포함 여부를 운영 코드에서 통일). 정치 속보 예외. 분량 채우기용 문장 금지.
- H1 제목 1개, 첫 2~3문장 직접 답변, H2 3~5개, 필요한 H3, 실제로 유용한 비교표/체크리스트, FAQ 2~4개(억지 삽입 금지), 최신성/출처/작성일·수정일, 핵심 키워드 자연스럽게 1개+연관어. 읽기 쉬운 2~4문장 단락. 색상 강조 박스·좌측 컬러 라인·짧은 요약. 제목에 불필요한 연도 금지.

## 작성·검수 프롬프트 템플릿
1. 블로그의 확정 라벨 4개 중 1개를 선택하고 핵심 독자와 검색 의도 1개를 정의한다.
2. 동일 주제의 WordPress 원문이 있다면 링크/사실만 검증하고 **완전히 다른 질문·구성·예시**로 글을 새로 작성한다.
3. 개별 페르소나와 톤을 적용하되 실제 취재·전문 자격·사용 경험을 꾸미지 않는다.
4. 권장 글 길이, 직접 답변형 서론, H2/H3, 실용 예시, FAQ, 출처/업데이트일을 충족한다.
5. 사진은 개별 목표 장수만큼 관련성이 높은 후보를 검색하되 권리·정확성·중복 여부를 확인하고 ALT를 기록한다.
6. 기사 품질/사실/저작권/중복/링크를 점검하고, 실제 발행 모드 충돌이 해소되기 전에는 비공개 초안만 만든다.
7. 완료 증거: 블로그 ID, 초안 ID/편집 URL, 검수 점수, 이미지 출처·ALT, 검증 로그. 공개 발행은 별도 승인 정책에 따른다.
