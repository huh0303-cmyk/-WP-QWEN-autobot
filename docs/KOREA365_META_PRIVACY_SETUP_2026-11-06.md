# Korea365 Meta privacy and deletion setup

- Privacy policy: https://korea365.org/privacy-policy/
- Data deletion instructions: https://korea365.org/data-deletion/
- Owner-approved domain: korea365.org
- Contact currently published on Korea365: huh0303@gmail.com

The workflow `.github/workflows/publish-korea365-meta-policy-pages.yml` updates the existing privacy page and creates/updates the data deletion page using the existing WordPress Application Password GitHub secret `KOREA365ORG`. It never prints or writes the credential.

The page content is scoped to the SIS Center Publisher Instagram/Threads account connection and publishing workflow. Public-page read-back is required before the URLs are entered into Meta app settings.

The Meta app form still needs a 1024x1024 icon and category selection. The Meta app's app-domain, terms-of-service URL, and privacy URL must be checked in the Meta dashboard before submission. Do not claim app review submission until Meta confirms acceptance.
