# 서울저널 × 서울 지수 멀티플랫폼 콘텐츠 운영 지침

## 1. 채널별 게시 대상
- YouTube: 서울저널(Seoul Journal) 채널에 게시한다.
- TikTok: 서울 지수 계정에 게시한다.
- Threads: 서울 지수 계정에 게시한다.
- Instagram: 서울 지수 계정에 게시한다. 세로 영상은 Reels 형식을 우선 사용한다.
- Facebook: 서울 지수 계정/페이지에 게시한다.
- 계정명만 비슷한 계정으로 대체하지 않는다. 게시 전 각 플랫폼에서 정확한 프로필명과 계정 식별자를 확인한다. 정확한 계정 연결이 검증되지 않으면 게시하지 않고 인증 대기 상태로 둔다.

## 2. 일일 최소 게시량
- 기본 목표: 하루 최소 7개의 콘텐츠.
- 황금 키워드 캘린더 기반: 5개 쇼츠.
- 반응형 핫이슈: 오전 1개, 오후 1개.
- 긴급 속보/중요 이슈는 위 7개에 추가 게시할 수 있다. 추가 게시가 기본 7개를 대체하지 않는다.
- 같은 원본 콘텐츠를 플랫폼별 화면비, 캡션, 해시태그, 길이 요구에 맞게 재편집할 수 있다. 플랫폼에 맞춘 수정은 하되, 확인되지 않은 사실을 덧붙이지 않는다.

## 3. 황금 키워드 5개
- Google Sheets의 연간 황금 키워드 캘린더에서 오늘 기준 약 4일 전 날짜의 5개 후보를 가져온다.
- 후보는 초안 소재일 뿐, 검색량이 높다는 증거로 간주하지 않는다.
- 게시 후보마다 당일 네이버 데이터랩 검색 추이와 같은 날의 미디어 노출/보도를 확인한다.
- 실제 추세·언론 근거가 확인되지 않으면 ‘검색량 검증 완료’로 표시하지 않는다. 캘린더 날짜 행이 없으면 날짜를 임의로 바꾸지 말고 누락 사유를 기록한다.

## 4. 반응형 2개 및 속보
- 오전 1개와 오후 1개를 당일·전일 가장 중요한 이슈로 선정한다.
- 정치 콘텐츠는 이재명과 한동훈 관련 이슈를 매일 점검하고, 해당 날짜에 보도 근거가 있는 주제를 선택한다. 근거가 없으면 억지로 이슈를 만들거나 오래된 내용을 오늘의 속보처럼 표현하지 않는다.
- 긴급 속보는 신뢰할 수 있는 복수의 출처 또는 명확한 공식 발표를 확인한 뒤 추가한다.
- 사실, 주장, 의혹, 전망을 명확히 구분하고 날짜·인용·맥락을 검증한다. 오해를 부르는 제목·썸네일이나 확인되지 않은 혐의 단정은 금지한다.

## 5. 경쟁 쇼츠 분석
- 대본을 만들기 전, 조회수 20만 이상인 관련 경쟁 Shorts를 최소 5개 확인한다.
- 각 영상의 URL, 조회수 확인 시각, 제목 구조, 첫 1~2초 훅, 전개 속도, 자막 밀도, 썸네일 구성, 댓글 유도 방식을 기록한다.
- 성공한 형식과 전달 기법만 학습한다. 원문 대본·고유한 표현·썸네일을 복제하지 않는다.
- 5개를 확인하지 못하면 ‘경쟁 분석 미충족’으로 기록하고 완료로 속이지 않는다.

## 6. 음성 및 영상 스타일
- 음성은 ElevenLabs만 사용한다. 기본 목표는 빠르고 에너지 높은 뉴스 진행, 높은 톤과 긴장감, 후처리 목표 속도 1.2배다.
- 졸린 말투, 느린 도입, 긴 인사말을 피한다. 첫 1~2초 안에 핵심 질문·충돌·놀라운 사실을 제시한다.
- 실제 오디오에서 속도/피치가 목표에 맞는지 검수한다. 제공 도구가 설정을 지원하지 않으면 지원한 척하지 말고 후처리 단계로 넘긴다.
- 세로형 9:16을 기본으로 하며, 플랫폼별 안전 영역과 자막 가독성을 확인한다.

## 7. 공통 썸네일 규칙 — 모든 YouTube 채널
- 공통 원칙: 어두운 배경, 높은 명암 대비, 큰 노랑/흰색/빨강 계열 제목, 모바일에서도 읽히는 짧은 문구, 한 장면에 하나의 핵심 메시지.
- 제목 문구는 짧고 명확하게 작성한다. 자극적이더라도 사실을 왜곡하지 않는다.
- 실제 인물·사건 이미지는 적법하게 사용할 수 있는 출처를 확인한다. 가짜 인물 이미지, 합성된 증거, 오해를 유도하는 시각 자료를 사용하지 않는다.
- 모든 채널에 동일한 시각 원칙을 적용하되, 채널별 주제와 브랜드에 맞게 문구·이미지를 달리한다.

## 8. 플랫폼별 게시 패키지
각 콘텐츠마다 아래 항목을 준비한다.
- 검색을 고려한 제목/첫 문장
- 사실 확인된 설명문
- 관련 태그·해시태그
- 9:16 영상과 자막
- YouTube용 썸네일(공통 썸네일 규칙 준수)
- 플랫폼별 캡션 및 댓글 유도 문구
- 원본 출처와 확인 시각
- 플랫폼별 게시 상태, 게시물 URL, 오류 로그

## 9. 게시 승인·보안
- YouTube의 서울저널, TikTok/Threads/Instagram/Facebook의 서울 지수 계정이 정확히 인증되었는지 확인한다.
- 현재 승인된 게시 권한이 확인되지 않은 플랫폼에는 게시하지 않는다.
- 사용자가 지정한 게시 계정 외 다른 계정으로 전송하지 않는다.
- 비공개 업로드가 요구된 YouTube 작업은 명시적 변경 전까지 PRIVATE 상태를 유지한다.
- 토큰·비밀번호·API 키를 저장소에 커밋하지 않는다. GitHub Secrets 환경변수로만 사용한다.

## 10. 완료 판정
- 매일 7개 이상의 편집 패키지가 생성되었는지 확인한다.
- 각 패키지에 출처 검증, 경쟁 쇼츠 분석(최소 5개), 음성 검수, 제목/설명/태그, 플랫폼별 계정 확인 상태가 기록되어야 한다.
- 실제 업로드는 플랫폼 응답으로 게시 URL 또는 게시 ID를 확인한 경우에만 완료로 표시한다.
- 워크플로우 실행 성공은 영상 제작 성공이나 게시 성공과 동일하지 않다.
