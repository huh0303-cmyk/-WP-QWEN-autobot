- 언어 선택: 베트남어(기본) / 영어 / 한국어 / 네팔어.
- 비자 정책 섹션: 정부 사이트 기준, 베트남부터.

- 미검증: 서류별 대학 요구 사항, 재정 증빙 금액, 베트남어·네팔어 번역 검수, 화면 렌더링.
