# 서울저널 국회·정부 영상 소스 및 편집 정책 (2026-11-12)

## 결론

- 국회 인터넷의사중계의 회의 영상은 상업적 목적으로 사용할 수 없다는 안내가 붙어 있다. 서울저널 수익화 영상에는 단순 출처표시만으로 사용하지 않는다.
- 국회방송 또는 국회 홈페이지의 개별 자료에 공공누리 제1유형이 실제 표시된 경우에만 그 표시가 적용된 저작물의 범위를 확인해 사용한다. 보도자료의 제1유형 표시는 링크된 방송 영상까지 자동으로 허락하지 않는다.
- 국회 회의 영상이 필요하면 「국회에서의중계방송등에관한규칙」 제11조의2에 따른 영상자료 제공 신청을 먼저 한다. 사용 목적·용도·일시·형태와 편집 계획, 유튜브 비공개 검수 절차를 적는다.
- 정부 발언 영상은 KTV 나누리에서 권리가 정비되어 개방된 촬영 원본·방송본·기획 콘텐츠를 우선 검토한다. 다운로드할 때 개별 자료 이용조건을 저장한다.
- 정책브리핑·부처 보도자료의 텍스트 공공누리 표시는 삽입 사진·영상·음원에 자동으로 확장되지 않는다.

## 국회에서 찾을 수 있는 자료

| 공급처 | 제공 내용 | 서울저널 사용 판단 |
|---|---|---|
| 국회 인터넷의사중계 | 본회의, 예산결산특별위원회, 상임위원회, 특별위원회 생중계·다시보기·자막·오디오, 기자회견 | 상업 이용 금지 안내. 수익화 편집 금지, 별도 제공 신청 필요 |
| 국회 영상회의록 | 당일 퀵 VOD, 과거 VOD, 문서 회의록·음성인식 자막 연계 | 회의 영상은 같은 제한으로 취급. 회의록은 사실확인·인용 근거로 사용 |
| 국회방송 NATV | 중계, 본회의·위원회, 국회뉴스, 입법정보·시사, 문화·교양, 기획특집, 온라인 콘텐츠 | 개별 페이지 공공누리 유형을 확인. 무표시 자료는 사전 문의 |
| 국회 홈페이지 | 보도자료, 공지, 의원·위원회·기관 자료 | 개별 게시물 하단 공공누리 표시가 있는 본문·첨부물만 해당 범위에서 사용 |

## 정부에서 찾을 수 있는 자료

| 공급처 | 제공 내용 | 서울저널 사용 판단 |
|---|---|---|
| KTV 나누리 | 대통령 주요 행보, 국무회의, 쌍방향 브리핑, 촬영 원본·방송본·기획 콘텐츠 | 최우선 후보. 가입 후 개별 다운로드 조건과 권리정보 보관 |
| KTV 국민방송 | 국무회의, 국가기념식, 정책·보도·특집, 부처 홍보영상 | 개별 공공누리 표시 확인. 무표시 자료는 KTV 아카이브 문의 |
| 정책브리핑·각 부처 | 브리핑 원문, 보도자료, 정책 설명 | 대본·사실확인에 사용. 사진·영상·음원은 별도 권리 확인 |
| 정부기관 공식 유튜브 | 브리핑·행사·정책 영상 | 공식 계정이라는 이유만으로 재사용 가능하지 않음. 설명란 라이선스 또는 서면 허락 필요 |

## 편집 전 필수 기록

1. 원본 제목, 행사·회의명, 날짜, 원본 URL, 다운로드 일시
2. 원본 페이지 화면과 공공누리 유형 또는 별도 허가서
3. 질문자·답변자, 소속·직함, 정확한 발언과 앞뒤 문맥 타임코드
4. 영상·음성·사진·음악 각각의 권리 상태
5. 편집구간, 자막 추가, 화면 확대 등 변경 내역
6. 먼저 비공개 업로드하고 사실·맥락·출처·제목을 검수한 기록

## 출처표시 문안

실제 공공누리 제1유형이 확인된 자료만 다음 형식을 쓴다.

> 출처: [기관명], 「[저작물명]」([발행연도/날짜]), [원본 URL], 공공누리 제1유형 / 편집: 서울저널(구간 발췌·자막 추가)

별도 제공 승인을 받은 국회 영상은 승인서의 지정 문구와 조건을 우선한다. 공공누리 표시가 없는 원본에 서울저널이 임의로 “공공누리 제1유형”을 붙이지 않는다.

## 제목·썸네일 원칙

- 관찰 가능한 행동과 실제 발언을 강하게 배치한다: “답변 끊고 재질문”, “3분간 맞붙은 쟁점”, “그 답변 책임질 수 있습니까?”
- “박살”, “굴복”, “거짓말 들통”처럼 사실판단을 단정하는 표현은 원본과 공식 기록이 직접 입증할 때만 쓴다.
- 실제 인물 1~3명, 작은 서울저널 로고, 현장 원본/국회 질의 배지, 흰색 첫 줄·청록색 둘째 줄, 재생시간을 기본 구성으로 한다.
- 합성 정치인 얼굴은 사용하지 않고, 권리 확인된 실제 사진 또는 허가받은 원본 프레임만 사용한다.
