# Instagram·Threads 운영 지침 — 2026-09-09

사용자의 최신 비용 중지 지침이 이전 유료 생성 허용보다 우선한다.

| 계정 이름 | 정보 주제 |
|---|---|
| Amazon | 건강 정보·건기식 성분 설명 |
| Ben | 여행 정보·예약 전 확인 요령 |
| Rosie | 생활 정보·살림 팁 |
| Jisoo | 뷰티·올리브영 등 제품 소개 |

- 각 계정 하루 두 개 정보 게시물을 목표로 한다. 판매·제휴·구매 유도 링크는 아직 넣지 않는다.
- Threads는 무례하지 않은 친근한 반말과 정보 권유형 문장으로 별도 작성한다.
- 소재의 사실·중복·사진 사용 권리를 확인한다. 실제 사용하지 않은 제품을 사용했다고 쓰거나 개인 경험을 꾸미지 않는다.
- 유료 텍스트·이미지·음성·영상 API를 호출하지 않는다. 자료가 없으면 준비 대기로 표시한다.
- 정보 선정 → 문안·이미지 준비 → 사실·중복·판매 링크 검토 → 대상 계정 확인 → 게시 → 실제 게시 ID/URL 확인 순서로 운영한다.
- TOPIK 교육 계정은 이 네 계정과 분리한다.

## 현재 검증 상태

현재 social-publish-one.yml과 meta_publish.py는 TOPIK·ENGLISH·LANGUAGE의 영상 수동 게시 경로만 지원한다. Amazon·Ben·Rosie·Jisoo의 계정 ID와 토큰 매핑, 정보 이미지/텍스트 게시 경로, 하루 두 번 예약, 실제 게시 성공 확인은 미완료다. 이 문서는 실행 완료 증거가 아니며, 네 계정 자동화가 완성됐다고 보고하지 않는다.
