## Format pivot
Prioritize actual authenticated politician speech and the interlocutor's genuine response over an AI anchor summarizing unrelated news. Structure: real verified quote as hook -> context -> actual response -> core disputed point -> neutral viewer question. Never manufacture dialogue or stitch statements to reverse their meaning.
