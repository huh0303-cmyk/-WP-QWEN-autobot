# CEO 종합상황실 — 모든 지표 전일 대비 증감 필수

사용자 확정: 2026-08-31. 채팅 보고, Google Sheets, 이메일, 대시보드 모두 적용한다.

## 변경 불가 표기 원칙

- WP 27개, Blogger 27개, YouTube 전체 보고 채널, SNS 전체 계정의 모든 성과 수치와 소계·합계는 반드시 `값(전일 대비 증감)`으로 표시한다.
- 방문자, 누적 방문, 구독자, 누적 조회, 팔로워 등 어떤 성과 지표도 숫자만 단독으로 보고하지 않는다.
- 고정 자산 수량, 행 번호, 날짜 등 식별·설정 정보는 성과 지표가 아니다.

| 상태 | 필수 표시 예시 |
|---|---|
| 증가 확인 | `1,815(+12)` |
| 감소 확인 | `1,815(-12)` |
| 같은 값임이 확인됨 | `1,815(0)` |
| 현재 값은 있으나 전일 비교값 없음·불일치 | `1,815(증감 미확인)` |
| 현재 값 수집 실패·미연결 | `미집계(증감 미확인)` |

## 계산·검증 기준

1. 보고 기준일과 수집시각, 시간대를 명시한다. 기본은 KST다. 어제 실적 보고는 어제 완료값과 전전일 완료값을 비교한다. 오늘 중간값을 어제 최종값으로 바꿔 표시하지 않는다.
2. 같은 계정/채널 ID, 같은 지표 정의, 같은 기간·마감 기준의 값끼리만 차감한다. 이름이 같아도 계정 매핑이 바뀌면 비교를 중단한다.
3. 누적 지표 증감은 같은 마감 기준의 누적값 차이다. 현재 누적값과 어제 증가분을 혼합해 전일 대비라고 표시하지 않는다. 역산값이면 산식과 한계를 밝힌다.
4. 방문자·조회수·구독자·팔로워는 서로 다른 지표다. 누적 조회수를 누적 방문자로 대체하지 않는다.
5. 값 없음, API 오류, 권한 없음, 전일 스냅샷 없음은 0이 아니다. 기본값 0 대입이나 `증감 미확인`을 `(0)`으로 치환하는 행위를 금지한다.
6. 합계에도 증감을 표시한다. 양일 동일한 자산 집합으로 비교한다. 일부만 수집됐으면 수집 범위와 제외 대상을 명시하고, 완전한 합계처럼 보고하지 않는다. 합계 증감을 검증할 수 없으면 `(증감 미확인)`이다.
7. 이전 표의 `(0)` 또는 `(+0)`도 근거 없이 재사용하지 않는다. 원본 값·비교일·계정 매핑을 확인한다.

## 보고 전 필수 확인

- [ ] 모든 성과 수치 및 소계·합계에 증감 괄호가 있는가?
- [ ] 비교 기준일과 단위가 명확하고 동일한가?
- [ ] 미집계와 실제 0을 구분했는가?
- [ ] 미확인 증감을 임의로 계산하거나 0으로 표시하지 않았는가?
- [ ] 누락 자산 및 오래된 스냅샷의 범위를 밝혔는가?

이 문서의 커밋은 보고 기준의 고정이다. 수집기·표시 코드 반영 및 실제 실행 검증 여부는 별도로 보고하며, 문서 추가만으로 자동화 적용 완료를 주장하지 않는다.
