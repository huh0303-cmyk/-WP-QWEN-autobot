# YouTube ElevenLabs voice migration — 2026-10-21

## Scope
Stable voice profiles were prepared for:
1. Health Clinic USA
2. Health Clinic Japan
3. NASA / NASA_XFILES
4. History Today / HISTORY_TV_TODAY
5. Retro USA / RETRO_USA1
6. Old Hollywood / SILENT_ERA_FILM
7. Seoul_Jisoo1 / @jisoopicks

The voice profile backup lives in `config/youtube_voice_profiles.json`. API keys are not stored in Git.

## Benchmarking basis
The channel choices are based on broad delivery traits rather than copying any real creator's identity:
- High-audience health channels such as Doctor Mike and Institute of Human Anatomy use clear, direct, audience-friendly explanations; Health Clinic should sound calm and credible, not sensational.
- NASA's large public channel demonstrates the value of precise, confident science communication; the NASA narration profile is measured and authoritative.
- Large history/documentary channels favor deliberate pacing, clear diction, and narrative emphasis; History Today and Old Hollywood use documentary-style delivery.
- Retro USA and Seoul_Jisoo1 use a warmer, conversational voice suitable for nostalgia and travel recommendations.

## Implementation
- `scripts/channel_long_video.py` now uses ElevenLabs TTS for the three channels it owns. It no longer silently falls back to Edge TTS for those channels; missing key/voice ID fails visibly.
- `.github/workflows/youtube-health-shopping-daily.yml` passes the existing ElevenLabs API key and the existing Health Clinic voice ID secrets. Seoul_Jisoo1 can use repository variable `ELEVENLABS_VOICE_ID_SEOUL_JISOO1`; if unset, the code uses the backed-up Bella premade voice ID.
- `scripts/knowledge_narrator.py` now pins stable narrator IDs by channel rather than randomly choosing a new voice each run. Existing code paths for NASA, History Today, Retro USA, and Old Hollywood pass the channel key into the selector.
- The selected defaults and per-channel override variable names are backed up in `config/youtube_voice_profiles.json`.
- `.github/workflows/elevenlabs-voice-audition.yml` is a manual, private audition only. It generates seven short MP3 samples and a manifest as a GitHub Actions artifact. It does not render full videos and does not upload anything to YouTube.

## Important limitations / approval gate
- This change does not prove that the current API key is valid or that all voice IDs are available in the user's ElevenLabs account. The manual audition workflow must be run and its artifact listened to.
- Health Clinic Japan intentionally requires the existing Japanese voice ID secret; it must not silently substitute an English voice.
- The knowledge channel code may run under the VPS worker/runtime rather than GitHub Actions. The GitHub source is updated, but production execution on that worker has not been verified in this commit.
- No workflow was dispatched as part of this change. No audio or video has been generated by this commit, and no content was published.
- Do not add API keys to GitHub repository variables or source files. Keep the API key in the existing `ELEVENLABS_API_KEY` secret.
