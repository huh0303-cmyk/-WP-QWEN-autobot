# 서울지수·서울크리스 운영원칙 및 운영지침

- 시행일: 2026-11-06
- 기준 시간대: Asia/Seoul
- 적용 계정: Instagram / Threads의 @seoul_jisoo, @seoul_chris
- 최상위 원칙: 상품 판매보다 재미·정보·공감·공유 가치가 먼저다.

## 1. 계정별 게시량과 시간
- 서울지수(@seoul_jisoo): 하루 서로 다른 주제 3개.
- 서울크리스(@seoul_chris): 하루 서로 다른 주제 3개.
- Instagram과 Threads 양쪽에 발행하되 플랫폼별 문체와 길이에 맞춰 별도로 작성한다.
- 매일 게시 시각은 한국시간 오전 8시부터 밤 11시 사이에서 무작위로 정한다.
- 같은 계정의 게시물 사이에는 최소 2시간 간격을 둔다.
- 두 계정의 게시 시각은 가능한 한 서로 분산한다.
- 누락된 게시물을 한꺼번에 몰아서 발행하지 않는다.
- 이 일정은 목표 정책이며, 인증·스케줄러·실제 게시 영수증이 확인되기 전에는 자동발행 활성 상태로 표시하지 않는다.

## 2. 편집 원칙: 콘텐츠 우선, 상품은 마지막
- 먼저 독자가 재미있게 읽고 공유할 수 있는 콘텐츠를 완성한다.
- 콘텐츠 자체만으로 정보·재미·토론 가치가 있어야 한다.
- 기본 편집 비중은 정보·재미 80~90%, 관련 상품 연결 10~20% 이하를 목표로 한다.
- 모든 글에 상품 링크를 강제로 넣지 않는다. 직접 관련 상품이 없으면 링크 없이 발행한다.
- 제휴 상품은 본문 뒤쪽 또는 마지막에 배치하고 제휴 관계를 명확히 고지한다.
- 사용자가 승인한 실제 쿠팡 파트너스 추적 URL만 사용한다. 추적 코드가 없는 일반 URL을 제휴 링크로 가장하거나 URL을 만들어내지 않는다.

## 3. 서울지수 — 건강·생활·사회 핫이슈
- 건강과 일상생활을 중심으로 정치, 사회, 경제, 스포츠, 연예, 소비자 이슈, 생활 트렌드를 폭넓게 다룬다.
- 오늘 화제의 뉴스, 의외의 사실, 잘못 알려진 상식, 생활 속 궁금증, 경기 결과와 주요 장면 등을 재미있고 쉽게 설명한다.
- 건강기능식품은 콘텐츠와 직접 관련이 있을 때만 소개한다.
- 건강 관련 내용은 근거·한계·주의사항을 함께 제시한다. 질병 진단, 치료 보장, 과장 효능, 공포 마케팅을 금지한다.

## 4. 서울크리스 — K-뷰티·피부관리·대중 트렌드
- K-뷰티, 피부관리, 화장품, 성분, 뷰티 산업 트렌드를 중심으로 한다.
- 연예·문화·사회·스포츠 등 대중적 핫이슈도 계정 분위기에 맞게 다양하게 다룬다.
- 피부관리 오해 바로잡기, 성분 설명, 제품 비교, 한국 뷰티 트렌드, 소비자 관점의 실용 팁을 활용한다.
- 화장품은 콘텐츠와 직접 관련이 있을 때만 소개하고 성분·용도·주의사항을 확인한다.
- 실제 사용하지 않은 제품을 사용했다고 말하거나 개인 경험·효과를 꾸며내지 않는다.

## 5. 매일 트렌드·키워드 조사
- 콘텐츠 작성 전에 네이버 데이터랩/검색 트렌드 및 네이버 뉴스에서 현재 관심 주제와 표현을 확인한다.
- 주요 언론과 신뢰할 수 있는 원문 출처를 교차 확인한다.
- 정치·사회·경제·스포츠·연예·건강·뷰티 주제를 균형 있게 순환한다.
- 네이버 검색어는 문맥에 자연스럽게 제목과 본문에 반영한다. 키워드 나열·반복 삽입은 금지한다.
- 실제 검색량 자료가 없으면 '검색량 1위' 또는 '노출량 최다'라고 단정하지 않는다.
- 기사를 베끼지 않고 사실관계를 재확인해 독자적인 문장과 관점으로 재구성한다.
- 정치 이슈는 확인된 사실, 의혹·주장, 의견을 분리한다. 스포츠 점수·일정·선수 정보는 최신 자료로 검증한다.

## 6. 플랫폼별 작성
- Instagram: 첫 화면에서 시선을 끄는 짧은 제목, 읽기 쉬운 카드/본문, 명확한 요점.
- Threads: 대화하듯 자연스럽고 친근한 문장, 한 가지 핵심, 의견을 나눌 질문.
- 같은 주제를 다루더라도 문장을 그대로 복사하지 않는다.
- 과장된 낚시 제목, 허위 긴급성, 확인되지 않은 루머를 금지한다.

## 7. 검수와 발행
- 계정별 하루 3개 주제가 서로 달라야 하며 최근 게시물과 중복을 검사한다.
- 출처, 날짜, 숫자, 인물·팀명, 상품 정보, 제휴 고지, 추적 URL을 검수한다.
- 계정 실체 확인, 플랫폼별 쓰기 권한, 미디어 공개 URL, 중복 방지, 게시 ID/URL 영수증이 모두 확인되어야 성공으로 기록한다.
- 로그인 세션이 있다는 사실만으로 API 게시 연결이 완료됐다고 판단하지 않는다.
- 게시 영수증이 없으면 '발행 완료'라고 보고하지 않는다.

## 8. 실행 환경 — VPS 사용 금지
- VPS, SSH, Linux 서버, systemd, 서버 로컬 큐, 서버형 n8n은 이 운영의 실행 경로에서 제외한다.
- SNS 계정 인증과 게시 작업은 사용자가 승인한 Windows 로컬 PC에서 Desktop Commander와 PowerShell을 중심으로 진행한다.
- GitHub는 코드·설정·운영지침·변경 이력 보관 및 버전 관리에 사용한다.
- control.korea365.org는 GitHub Pages 기반 운영 대시보드이며 운영원칙과 현재 상태를 보여준다.
- 로컬 PC가 꺼져 있거나 로그아웃·인증 만료 상태이면 로컬 자동발행이 실행되지 않을 수 있다. 이를 24시간 무인 서버 운영으로 설명하지 않는다.
- 비밀번호, OAuth 토큰, 쿠키, API Secret, 파트너 추적 비밀값은 GitHub·문서·채팅에 기록하지 않는다.

## 9. 이전 지침과의 우선순위
- 이 문서와 `config/sns_six_channel_policy.json`은 서울지수·서울크리스의 최신 운영 기준이다.
- 2026-11-06 이전의 하루 1회/2회 게시, 기존 계정 핸들, 기존 역할 설명 및 VPS 실행 지침은 이 범위에서 폐기·대체한다.
- 과거 기록은 감사·복구 목적의 참고 자료로만 보존하며 현재 실행 지침으로 사용하지 않는다.
