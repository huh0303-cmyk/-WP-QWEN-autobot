# YouTube Playlist Channel Publishing Policy

**Status:** Required operating rule  
**Applies to:** Every YouTube channel classified as a playlist channel in the London Project  
**Owner:** London Project operator / assigned content staff

## 1. Publishing frequency

- Publish **2–3 videos per week per playlist channel**.
- This rule applies to playlist channels only; do not silently apply it to knowledge, language, health, or shopping channels.
- Use the channel's configured workflow and scheduling controls. Before scheduling, confirm the intended channel ID and local publication time.
- If a channel cannot publish, record the exact blocker and retry only that channel. Do not report a dispatch as a successful public publication.

## 2. Thumbnail research is mandatory

Before creating a thumbnail for each playlist video:

1. Search YouTube for videos in the **same content category / audience niche**.
2. Identify relevant examples with **at least 1,000,000 views**. Prefer recent examples when the niche changes quickly, and use more than one reference when practical.
3. Record the reference video's title, URL, view count observed, and the date checked in the content task record.
4. Analyze and use as inspiration the thumbnail's high-level presentation: focal subject, contrast, color palette, composition, text amount/readability, emotional tone, and visual hierarchy.
5. Create an original thumbnail for our video. **Do not copy or reuse another creator's thumbnail, artwork, logo, or copyrighted image.** Do not imply an endorsement or affiliation.

If no suitable 1M+ example can be found, note the search terms and result, use the closest relevant high-performing examples available, and flag the exception for review. Never fabricate a view count or claim that a reference meets the threshold without checking it.

## 3. Per-video pre-publication checklist

- [ ] Correct playlist channel and channel ID selected
- [ ] Topic and playlist fit the channel's established category
- [ ] Weekly schedule remains within 2–3 publications for this playlist channel
- [ ] Thumbnail research references (1M+ views) recorded, or exception documented
- [ ] Original thumbnail created; no copied thumbnail/artwork
- [ ] Title, description, language, and any rights/attribution details checked
- [ ] Video and audio assets are owned, licensed, public-domain, or otherwise authorized for use
- [ ] Correct workflow and publishing status verified
- [ ] After publishing, public video URL and publication timestamp saved as evidence

## 4. Reporting and safety rules

For each channel, report: channel name, handle, channel ID, planned weekly frequency, workflow, next scheduled item, latest public video URL, thumbnail-reference evidence, and status/blocker.

Use these status meanings:
- **Published:** Public URL verified.
- **Scheduled:** Schedule visibly confirmed in the platform/workflow.
- **Dispatched:** Workflow accepted the request only; not proof of publication.
- **Blocked:** State the exact reason and evidence.
- **Unverified:** No sufficient evidence yet.

Do not claim that a channel is connected, scheduled, or publishing unless the corresponding evidence has been checked. Do not delete existing content or change production settings as part of this policy update.

## 5. Confirmation requirement

Before marking a playlist channel as compliant, verify its actual registration and workflow. The overall YouTube target inventory is currently expected to be **23 channels**: 5 knowledge, 10 language, 5 playlist, 2 health, and 1 shopping. This is a target to reconcile against the actual registry, not proof that all 23 are currently configured. Record missing or extra channels explicitly.
