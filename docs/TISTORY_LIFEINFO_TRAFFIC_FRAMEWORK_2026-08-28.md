## 검색 유입형 글 구조

- 제목: `대상/노선/행사 + 연도·회차 + 사용자가 바로 찾는 행동`
- 첫 문단: 대상, 핵심 날짜, 현재 확인 상태를 3~4문장으로 요약
- 본문: 대상 → 일정 → 신청·예매 방법 → 준비물·결제 → 변경·취소 → 공식 확인처
- 표: 날짜·노선·등급 등 비교가 실제로 필요할 때만 사용
- 끝부분: 기준일, 공식 출처 링크, 변경 가능성 안내
- 글마다 하나의 검색 의도만 완결하며 유사 키워드 글을 여러 개 양산하지 않는다.

예시 제목 패턴:

- `2026 근로장려금 신청 대상·기간·지급일 확인 방법`
- `KTX 서울–부산 시간표 확인과 승차권 예매 방법`
- `SRT 명절 승차권 예매 일정·대상 노선·취소수수료`
- `고속버스 시간표 조회와 모바일 표 예매·환불 방법`

## RSS 정책

- 한국생활정보의 발행 RSS는 전체 공개·최근 50개를 유지한다.
- RSS는 검색엔진과 구독자가 새 URL을 발견하도록 돕는 보조 수단이지 순위나 클릭을 보장하는 장치가 아니다.
- 외부 RSS는 소재 발견에만 사용한다. 제목·본문·사진을 복제하지 않는다.
- RSS에서 발견한 소재도 게시 전 공식 원문에서 날짜·금액·대상·노선·수수료를 다시 검증한다.
- 중단되거나 오류가 반복되는 피드는 자동으로 제외한다.

## 발행 안전장치

- 초기 상한은 주 3건이며 자동 공개하지 않는다.
- 날짜·금액·대상·지급일·시간표·수수료에는 기준일과 공식 링크가 필요하다.
- 확인되지 않은 `확정`, `전 국민`, `오늘 마감`, `100% 지급` 표현을 금지한다.
- 기존 반려동물 글은 삭제하거나 새 생활정보 카테고리로 잘못 재분류하지 않는다. 새 카테고리를 별도로 만들고 과거 글 정리는 별도 승인 후 진행한다.
- sitemap.xml과 `/rss`의 HTTP 상태를 정기적으로 검사하고 GSC에는 sitemap을 제출한다.
