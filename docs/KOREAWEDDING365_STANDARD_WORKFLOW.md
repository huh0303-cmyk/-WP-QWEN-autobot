# KoreaWedding365 표준 워크플로우

사이트: https://koreawedding365.com
예상 대상: 공개 글 132개(실행 시 재확인)
최종 KPI: 각 공개 글 맨 아래 공식 Coupang Partners 상품 8개, 예상 총 1,056개.
실행 방식: ChatGPT + Desktop Commander + PowerShell + GitHub.
금지: WPVibe 사용, 게시글 삭제, 미디어 원본 삭제.

## 고정 실행 순서
0. 사전 백업 및 기준선: 공개 글 ID, URL, 제목, 상태, 날짜, slug, 대표 이미지, 본문 해시를 저장한다.
1. 제목·본문 중복 점검: 완전/유사 제목 중복, 반복 문구, 제목-본문 불일치를 전수 감사한다.
2. 편집 수정: 실제 중복/불일치만 수정한다. 글 삭제 금지, URL/slug/의미 보존.
3. 이미지 전수 점검 및 수정: 대표/본문 이미지 중복, 깨짐, 주제 부적합을 확인하고 필요한 부분만 수정한다. 미디어 원본은 삭제하지 않는다.
4. 편집·이미지 재검증: 제목, 본문, 이미지, URL, 게시 상태를 다시 읽어 확인하고 미해결 항목을 기록한다.
5. 공식 상품 링크 풀 확보: 아래 40개 후보를 검색해 실제 상품명, 계정에서 생성한 공식 제휴 URL, 공식 이미지, 상품 식별자를 확보한다. 검색 화면 주소와 일반 상품 URL은 제휴 링크가 아니다.
6. 상품 삽입: 0~5단계 완료 증거가 모두 있을 때만 각 글 맨 아래 8개 삽입. 글 내부 상품 중복 금지.
7. 공개 페이지 전수 검증: 각 글 상품 8개, 공식 링크, 이미지, 배치 위치를 확인하고 실패 글은 재처리한다.
8. 종료 보고: 성공/실패 수량, 미해결 사항, 증거 및 GitHub 기록을 저장한다.

## 상품 배분
각 글에 주제 연관 1~2개, 한국 관련 1~2개, 프리미엄 1~2개, 인기/핫템 1~2개, 한국 뷰티/건강 1~2개를 균형 배분한다. 합계는 반드시 8개이며 각 글 안에서 중복하지 않는다.

## 운영 규칙
- 사용자가 "다음"이라고 하면 현재 단계와 증거를 확인하고 다음 미완료 단계 하나만 진행한다.
- 단계 시작 시 상태를 in_progress, 증거 확인 후 completed로 기록한다.
- 모든 대량 변경은 dry-run 보고서를 먼저 만들고 검토 후 apply한다.
- 게시글, 미디어 첨부파일, URL/slug, 게시 상태, 날짜, 카테고리, 태그, SEO 메타데이터를 임의 변경하지 않는다.
- 제목은 실제 중복/불일치가 확인된 경우에만 수정하고 검색 의도와 본문 의미를 보존한다.
- 쿠팡 계정에서 생성한 공식 제휴 URL/이미지 태그만 사용한다. 추정 URL 금지.
- WPVibe 금지. DC/PowerShell 및 검증 가능한 WordPress REST 절차 사용.
- Git에서는 이 워크플로우 전용 파일만 stage한다. 기존 변경사항을 덮어쓰거나 무관한 파일을 포함하지 않는다.
- 중단 후에는 상태 JSON과 최근 보고서를 확인해 마지막 증거가 있는 단계부터 재개한다.
- 상품 삽입은 마지막 콘텐츠 작업이며 앞 단계가 끝나기 전에는 시작하지 않는다.
