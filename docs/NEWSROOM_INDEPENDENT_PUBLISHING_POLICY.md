# 신문사 2개 독립 운영 정책 — 사용자 확정 (2026-08-31)

이 문서는 **KoreaNews365**와 **The Seoul Journal**의 최종·영구 운영 기준이다.
일반 WordPress/Blogspot 콘텐츠 정책과 충돌하면 이 문서가 우선한다.

## 적용 대상

- `koreanews365.com` — KoreaNews365
- `theseouljournal.com` — The Seoul Journal

## 절대 원칙

1. 일반 WordPress 25개의 특A/A/B 발행 빈도는 폐지하고 모두 사이트별 하루 1회, 주 7회로 운영한다. 두 신문사는 이 일반 정책의 예외로 독립 운영한다.
2. 일반 블로그의 최소·최대 글자 수 기준을 두 신문사에 적용하지 않는다.
3. 짧은 속보·브리핑도 사실과 출처가 확보되면 발행할 수 있다.
4. 기사 길이는 관찰·로그용 참고값일 뿐, 초안 선택·재생성·발행 차단 사유가 아니다.
5. `skip_newsroom_too_short`와 `skip_newsroom_too_long` 같은 길이 차단 상태를 다시 도입하지 않는다.
6. 최신 RSS·공식 발표·신뢰 가능한 원문을 기준으로 신속하게 처리한다.
7. 출처 표기, 사실 확인, 허위 인용·통계 금지, 중복 방지는 그대로 유지한다.
8. KoreaNews365는 한국어, The Seoul Journal은 영어로 운영한다.
9. 각 뉴스룸은 적격 RSS를 기준으로 하루 3~10회, 주 21~70회 독립 운영한다. 임의의 무작위 목표로 속보 처리를 조기 중단하지 않는다. 적격 RSS가 없으면 수량을 채우기 위해 기사를 만들지 않는다.
10. 일반 블로그/Blogspot의 선행 작업, 황금키워드 검증대기, WP 선행대기 때문에 뉴스 발행을 막지 않는다.
11. 유효한 날짜·출처가 있는 속보/긴급 RSS를 일반 기사보다 먼저 처리한다. 사실·출처·중복 검증은 생략하지 않는다.
12. 카테고리를 실제 WordPress 분류에 연결해 기사 상단에 색상 라벨로 표시한다. 영어 군사 분류는 Military다.
13. 기존 사람 검토·직접 공개 원칙을 유지한다. 속보 우선은 자동 공개 승인을 의미하지 않는다.

## 코드 잠금

- 실행 코드: `scripts/autopost_mega.py`
- 두 뉴스 모드(`news`, `news_en`)는 기사 길이를 출력만 하고 발행 조건으로 사용하지 않는다.
- 일반 블로그 길이·SEO·검수 기준은 변경하지 않는다.
