# 신문사 2개 독립 운영 정책 — 사용자 확정 (2026-09-09)

이 문서는 **KoreaNews365**와 **The Seoul Journal**의 최종·영구 운영 기준이다.
일반 WordPress/Blogspot 콘텐츠 정책과 충돌하면 이 문서가 우선한다.

## 적용 대상

- `koreanews365.com` — KoreaNews365
- `theseouljournal.com` — The Seoul Journal

## 절대 원칙

1. 일반 WordPress 25개의 특A/A/B 발행 빈도는 폐지하고 모두 사이트별 하루 1회, 주 7회로 운영한다. 두 신문사는 이 일반 정책의 예외로 독립 운영한다.
2. 일반 블로그의 최소·최대 글자 수 기준을 두 신문사에 적용하지 않는다.
3. 짧은 속보·브리핑도 사실과 출처가 확보되면 발행할 수 있다.
4. 기사 길이는 관찰·로그용 참고값일 뿐, 초안 선택·재생성·발행 차단 사유가 아니다.
5. `skip_newsroom_too_short`와 `skip_newsroom_too_long` 같은 길이 차단 상태를 다시 도입하지 않는다.
6. 최신 RSS·공식 발표·신뢰 가능한 원문을 기준으로 신속하게 처리한다.
7. 출처 표기, 사실 확인, 허위 인용·통계 금지, 중복 방지는 그대로 유지한다.
8. KoreaNews365는 한국어, The Seoul Journal은 영어로 운영한다.
9. RSS 새 기사 감지 시 자동 처리한다. 일일 발행 횟수 제한 없음. 하루 3~10회·주 21~70회 및 고정 편집 슬롯 정책은 폐지한다. 새로운 적격 기사가 없으면 발행하지 않는다.
10. 일반 블로그/Blogspot의 선행 작업, 황금키워드 검증대기, WP 선행대기 때문에 뉴스 발행을 막지 않는다.
11. 유효한 날짜·출처가 있는 속보/긴급 RSS를 일반 기사보다 먼저 처리한다. 사실·출처·중복 검증은 생략하지 않는다.
12. 카테고리를 실제 WordPress 분류에 연결해 기사 상단에 색상 라벨로 표시한다. 영어 군사 분류는 Military다.
13. 두 뉴스룸은 사용자 요청에 따라 RSS 새 기사 기반 자동 운영한다. 사실·출처·중복·품질 검증을 통과한 경우 기존 자동 공개 경로를 사용한다. 일반 블로그와 Tistory의 승인 규칙은 변경하지 않는다.

## RSS 감시와 새 기사 처리

- VPS의 `korea365-operations.service`가 RSS를 확인한다. 확인 주기(기본 60초)는 발행 예약이나 발행 횟수가 아니다.
- 원문 URL과 뉴스룸으로 만든 고유 식별자를 SQLite에 저장한다. 새 기사만 접수하고, 같은 기사는 다시 접수하지 않는다.
- 최초 실행은 기존 RSS 항목을 기준점으로 기록한다. VPS 교체로 과거 기사를 한꺼번에 발행하지 않는다.
- 새 기사의 정확한 `source_url`을 GitHub 게시 작업에 전달한다. 해당 기사 대신 다른 기사를 임의로 선택하지 않는다.
- 기사 수는 RSS와 검증 결과에 따라 달라진다. 일일·주간 수량 목표나 상한을 두지 않는다.
- 한국어 뉴스룸은 조선일보·동아일보·한겨레, 영어 뉴스룸은 CNN·뉴욕타임스의 설정된 RSS를 감시한다. 연결 실패는 매체별로 표시하며 정상이라고 가장하지 않는다.
- 제목·링크는 취재 단서로 사용한다. 출처와 사실을 확인해 자체 기사를 작성하며 원문 문단·사진을 복제하지 않는다.
- 처리 중인 기사, 검수 실패, 공개 게시 결과를 통제실 이력에 남긴다. 전달 결과가 불명확하면 중복 발행을 피하도록 보류한다.
- registry의 뉴스룸 빈도 필드 0은 기존 슬롯 스케줄러에서 제외한다는 뜻이다. RSS 게시량의 상한이 0이라는 뜻이 아니다.

## 코드 잠금

- 실행 코드: `scripts/autopost_mega.py`
- RSS 감지 후 실행되는 게시 코드: `.github/workflows/newsrooms-daily-publisher.yml`
- 두 뉴스 모드(`news`, `news_en`)는 기사 길이를 출력만 하고 발행 조건으로 사용하지 않는다.
- 일반 블로그 길이·SEO·검수 기준은 변경하지 않는다.
