# 신문사 2개 독립 운영 정책 — 런던프로젝트 정본 (2026-09-16)

이 문서는 **KoreaNews365**와 **The Seoul Journal**의 독립 운영 기준이다.
일반 WordPress/Blogspot 콘텐츠 정책과 충돌하면 이 문서가 뉴스룸에 우선한다.

## 적용 대상

- `koreanews365.com` — KoreaNews365
- `theseouljournal.com` — The Seoul Journal

## 절대 원칙

1. 일반 WordPress 25개는 사이트별 하루 1회, 주 7회가 원칙이다. 두 신문사는 이 일반 정책의 예외로 독립 운영한다.
2. 일반 블로그의 최소·최대 글자 수 기준을 두 신문사에 기계적으로 적용하지 않는다.
3. 짧은 속보·브리핑도 사실과 출처가 확보되면 발행할 수 있다.
4. 기사 길이는 관찰·로그용 참고값이며 사실·출처·중복 검증이 우선이다.
5. `skip_newsroom_too_short`와 `skip_newsroom_too_long` 같은 단순 길이 차단 상태를 다시 도입하지 않는다.
6. 최신 RSS·공식 발표·신뢰 가능한 원문을 기준으로 신속하게 처리한다.
7. 출처 표기, 사실 확인, 허위 인용·통계 금지, 중복 방지는 유지한다.
8. KoreaNews365는 한국어, The Seoul Journal은 영어로 운영한다.
9. RSS 새 기사 및 속보 감지 시 자동 처리한다. **각 뉴스룸의 운영 목표는 KST 하루 3~10건이며, 하드 상한은 10건이다.** 적격하고 검증된 소스가 3건보다 적으면 숫자를 맞추려고 기사를 만들지 않고 실제 확인 가능한 기사만 발행한다. 고정 편집 슬롯은 두지 않는다.
10. 일반 블로그/Blogspot의 선행 작업, 황금키워드 검증대기, WP 선행대기 때문에 뉴스 발행을 막지 않는다.
11. 유효한 날짜·출처가 있는 속보/긴급 RSS를 일반 기사보다 먼저 처리한다. 사실·출처·중복 검증은 생략하지 않는다.
12. 카테고리를 실제 WordPress 분류에 연결해 기사 상단에 색상 라벨로 표시한다. 영어 군사 분류는 Military다.
13. 두 뉴스룸은 RSS 새 기사 기반 자동 운영한다. 사실·출처·중복·품질 검증을 통과한 경우 기존 자동 공개 경로를 사용한다. 일반 블로그와 Tistory의 승인 규칙은 변경하지 않는다.

## RSS 감시와 새 기사 처리

- VPS의 `korea365-operations.service`가 RSS를 확인한다. 확인 주기 자체는 발행 예약이나 발행 횟수가 아니다.
- 원문 URL과 뉴스룸으로 만든 고유 식별자를 SQLite에 저장한다. 새 기사만 접수하고 같은 기사는 다시 접수하지 않는다.
- 최초 실행은 기존 RSS 항목을 기준점으로 기록한다. VPS 교체로 과거 기사를 한꺼번에 발행하지 않는다.
- 새 기사의 정확한 `source_url`을 게시 작업에 전달한다. 해당 기사 대신 다른 기사를 임의로 선택하지 않는다.
- **각 뉴스룸은 검증 가능한 RSS/속보 기사 기준 하루 3~10건을 목표로 하되 최대 10건까지만 dispatch한다.** 적격 소스가 부족하면 3건 미만도 허용하고, 다음 KST 일자로 넘어간 대기 기사는 중복·신선도 검사를 다시 받는다.
- 제목·링크는 취재 단서로 사용한다. 출처와 사실을 확인해 자체 기사를 작성하며 원문 문단·사진을 복제하지 않는다.
- 처리 중인 기사, 검수 실패, 공개 게시 결과를 런던프로젝트 task_id 원장에 남긴다. 전달 결과가 불명확하면 중복 발행을 피하도록 보류한다.
- registry의 뉴스룸 빈도 필드 0은 기존 고정 슬롯 스케줄러에서 제외한다는 뜻이며 RSS 상한 0이라는 뜻이 아니다.

## SEO 비적용

14. 두 신문사는 SEO 점수를 발행 조건으로 쓰지 않는다. 초안 채택·재작성 여부는 사실관계·출처·중복 검사로 결정한다.
15. SEO 점수는 참고값이며 사실·출처 검증을 대체하지 않는다.
16. 뉴스 모드의 짧은 기사도 정보가 충분하면 길이를 억지로 늘리지 않는다.

## 발행 빈도 상한

17. 일반 WordPress 25개는 사이트당 KST 하루 1건을 원칙으로 한다. 원래 주제와 맞지 않는 소재를 어뷰징 목적으로 섞지 않는다.
18. 두 신문사는 RSS로 들어오는 적격 기사 기준 **목표 3~10건, 하드 상한 10건**이다. 상한은 안전판이며 적격 기사가 부족하면 그보다 적게 발행한다.

## 뉴스 사진 소싱 우선순위

19. 저작권 안전성이 확인된 이미지를 우선한다. 다음 순서로 시도한다.
    1. 검증된 공공저작물·퍼블릭도메인·재사용 허용 공식 사진
    2. 관련성이 확인된 무료 스톡 사진 — Pexels → Pixabay
    3. 승인된 AI 이미지 — SDXL Lightning → FLUX Schnell
    4. 위 단계가 모두 실패하거나 부적합하면 사진 없이 텍스트만
20. 연합뉴스·YTN 등 일반 언론사 사진은 공공저작물이 아니므로 라이선스 없이 복사하지 않는다. 원 출처의 사진 사용권이 명확하지 않으면 무료 스톡·AI·무이미지 경로를 사용한다.

## 런던프로젝트 기록

21. 기사 감지부터 발행·실패·재시도·감사까지 동일 task_id에 연결한다.
22. RSS dispatch 성공은 공개 발행 성공과 다르다. 실제 공개 URL과 HTTP/게시물 식별을 Audit Engine이 확인해야 VERIFIED_COMPLETE가 된다.
23. 실패한 기사 작업도 삭제하지 않고 원인과 마지막 상태를 보존한다.
