# CEO 통제실 알림 정책 잠금

- 정상 초안 생성, 비공개 업로드, 검토 준비 완료는 이메일·카카오를 발송하지 않는다.
- 정상 결과와 관리자 검토 링크는 `CEO종합상황실` Google Sheet 및 `control.korea365.org`에서 확인한다.
- 일일 CEO 종합보고 1회와 실패·긴급 장애 알림은 유지한다.
- 정상 완료 이메일이 다시 필요할 때만 실행 환경에 `NORMAL_COMPLETION_EMAIL_ENABLED=true`를 명시한다.
- 자동 공개는 금지한다. 최종 공개는 각 플랫폼 관리자 화면에서 사용자가 직접 실행한다.
